# 2026-11-22

## P3 体验补强（用户要求"都做"）

### 1. 段落级对齐 + 页码
- `Section.paras: [{page, text}]`，`split_sections_md` 按空行切段并记起始页；blocks 后端用 `_fill_paras_as_fallback` 兜底
- `translate.translate_paragraphs()`：按字符预算把段落分批，用 `[1] ... [2] ...` 编号一次翻多段，再用正则拆回
- **模型不按编号输出时整批退化为一块**并标 `aligned=false`，界面显示"未按段对齐"——宁可退化，也不要错位
- 实测 ResNet 218 段，全部带页码；`out/*.zh.md` 每段前带 `p3` 标记

### 2. 翻译缓存（app/cache.py）
- 键 = `模型|目标语言|术语库版本|原文sha256`；术语库版本 = 条数+最大id+最后修改时间
- 实测摘要第二次 0.01s 全命中；方法章 24 段全缓存
- 副作用收益：任务表在内存、重启会丢，但有缓存后重跑几秒复原

### 3. 术语候选面板
- 术语库弹窗加「从当前论文挖候选」，勾选 → `/api/terms/accept`
- 补完四步闭环第 2 步（人工确认）

### 4. 笔记编辑 + 批注
- `note.user_note` 列（PRAGMA 检查后 ALTER 补列）；`POST /api/note/<id>` 支持部分更新
- 导出 Markdown 自动附「我的批注」

### 5. 任务取消 + 队列
- `_RUN_SLOTS = Semaphore(1)`；拿不到就 `status=queued` 并阻塞等待
- worker 在章节之间检查 `cancel` 标记；取消后保留已译段落
- 实测：并发两个任务 → 一个 running 一个 queued；取消后状态 cancelled
