# 2026-11-22（晚）

## P4：用户指出界面粗糙，逐条修

用户原话：图表直接不见了、跑完大量没翻译、下拉菜单跑到左上、右边要素太空、不该只绑本地模型、"借鉴 GitHub 要直接抄代码不是抄形式"。

### 1. 图表丢失（根因）
- `ParsedPaper` 原本**没有图表字段**，`_md_to_lines` 把表格拍平成文字、图内文字整块丢弃
- 现在：`Section.tables`（结构化行）、`ParsedPaper.figures`（内嵌位图 >150px）、`page_images`（每页 110dpi 快照兜底矢量图）
- 图存 `data/media/<pdf md5 前12位>/`，`/media/...` 路由对外提供
- 实测：ResNet 15 个表格渲染成功、每节都有原页；ViT 抽出 39 张插图；Attention 3 张
- 前端：表格按 `<table>` 渲染（表头 th）、插图点击放大、`查看原文页` 折叠项

### 2. 大量章节没翻译（根因）
- 前端 `all` 只传固定 kind 列表，`other` 类章节（Preliminaries/Performance Profiling…）被漏掉
- 现在 `all` 传 `["*"]`，服务端解释为"除 references/acknowledg/front 外全部"
- 题名页排除：否则出现 "Kaiming He → Kaiming He" 这种噪音
- 未翻译章节也带英文原文（构建 sections 时先填 source），不再是空白

### 3. 轮询占位与正文互相覆盖（卡在"翻译中"）
- `poll()` 里创建 `#runningTip`，`renderRead()` 又会整体重写 `#center`，两者 ping-pong，最后占位赢
- 修法：有章节后完全交给 `renderRead`，占位只在解析阶段用；sig 里加入 stage 和 progress

### 4. 原生 select 弹层跑到左上
- 换成自定义 `.dd` 下拉（翻译范围、模型选择都用它）

### 5. 云端模型（app/settings.py）
- 提供方：local / deepseek / doubao / custom，全部走 OpenAI 兼容协议
- 密钥只存 `data/settings.json`，接口回传时只给 `has_key`
- 缓存键加入 `provider:model`，切模型不复用旧译文
- 前端右上角切换，缺密钥自动弹配置框并测连通

### 6. 右栏 AI 总结（app/summarize.py + SUMMARY_SYSTEM）
- 五段式：解决什么 / 怎么做的 / 结果（带数字）/ 局限 / 该不该读
- 实测 ResNet 324 字，数字来自正文（3.57%、152 层、ILSVRC 2015）

- 图表仍集中显示在章节末尾，未还原到正文原位（需要版面块坐标）
