## 本地网页界面（P0-5 完成，用户已定"本地网页"方案）

### 实现
- `web_server.py`：**只用标准库 `http.server`**，不引入 Flask/FastAPI。理由：端侧产品不该为界面多背运行时，演示时 `python web_server.py` 就能起
- 监听 `127.0.0.1:8000`（刻意不绑 0.0.0.0）
- `web/static/index.html`：单页三栏（章节 / 原文+译文 / 要素+证据+笔记），深色主题，无前端框架
- 接口：health / terms(增删导出) / terms/candidates / upload / run / task/{id} / task/last / notes / note/{id}
- 任务在内存 dict 里，后台线程跑链路，前端 700ms 轮询

### 关键设计决定
- 翻译按章节推进并回写 `sections[i].translation`，前端能"边翻边读"，不必等全篇
- `/api/task/last` 让刷新页面能接回上一次结果（也方便我截图验证）
- 上传按 **MD5 前 10 位 + 原名** 命名，同一篇论文重复上传不堆副本
- 轮询时用 sig 比对跳过重绘，并保留 scrollTop——否则阅读位置每 700ms 弹回顶部

1. 标题显示成 `1795243598_resnet`：上传加时间戳前缀后没还原，改为正则去前缀（现为哈希前缀 `^[0-9a-f]{10,}_`）

4. 无头 Chrome 截图验证界面：初始态、完成态均正常
