## 做法：引入 Section.flow

之前段落和图表是两套数据，渲染时只能"段落全写完，图表堆末尾"。
现在每个章节多一个 `flow`，按版面顺序存：

```json
[{"type":"text","para":0}, {"type":"table","page":4,"html":"..."},
 {"type":"formula","page":3,"bbox":[...],"latex":"...","path":"..."},
 {"type":"figure","page":2,"bbox":[...],"caption":"Figure 2. ...","path":"..."}]
```

- `text` 只存 `paras` 下标，翻译仍按 `paras` 回填，翻译逻辑零改动
- 渲染时按 flow 顺序输出，图表自然回到原位

## 解析层：MinerU 路径不再走 markdown

`_sections_from_mineru(blocks)` 直接按块建章节：
- `paragraph_title` + `_title_hashes()=="##"` → 开新章节
- `###`（如 "3.1 Residual Learning"）→ 当段落留在正文
- `text` → 段落（带 bbox）
- `table` → flow 项（HTML + 二维行）
- `image`/`chart` → flow 项（bbox + 图注）
- `equation` → flow 项（LaTeX 在 `text` 字段）
- `page_number`/`page_footnote`/`aside_text`/`doc_title` → 丢弃

快速档（PyMuPDF）没有 bbox，flow 为空，前端自动退回"段落 + 末尾图表"。
