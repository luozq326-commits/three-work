# 2026-11-22（深夜三）KaTeX + 快速档回原位

用户让"改好"两件事：① 快速档图表堆末尾 ② 公式没有 MathML。

## 1. KaTeX 本地包

- `npm pack katex`（0.19.1）→ 只拷 `katex.min.js` / `katex.min.css` / `fonts/*.woff2`
- 落地 `web/static/vendor/katex`，**0.5MB / 20 个 woff2**，不依赖 CDN
- 渲染：`katex.render(tex, el, {displayMode:true, throwOnError:false})`
- 失败兜底：`el.replaceWith(<code>)` 显示 LaTeX 源码
- 原图保留在渲染结果下方做对照（`（上为渲染，下为原图）`）
- 验证：DOM 里 `class="katex"` 2 个、`katex-mathml` 2 个、`annotation encoding="application/x-tex"` 2 个

## 2. 快速档回原位

关键发现：`pymupdf4llm.to_markdown(page_chunks=True)` 的每个 chunk 带 `page_boxes`，
里面有 `class`（text / section-header / picture / table / formula / page-footer…）和**绝对 bbox**。

做法（`_layout_flow`）：
1. 每个 box 用 `page.get_textbox(rect)` 取出文字，归一化（只留小写字母数字）后缓存
2. 每个段落（来自 markdown，文字质量好）用归一化前缀匹配 box，得分 ≥0.5 才认领 bbox
3. 媒体块全局收集，按 `(页, y)` 归属到"起始位置在它之前的最后一个章节"
   —— 不能按页区间分配，同页多章节会重复展示同一张图（第一版就踩了）
4. 每章 `flow` 按 `(页, y, x)` 排序

细节：
- 公式框又扁又矮，用 `dpi=220, min_w=20, min_h=8`，否则被尺寸门槛滤掉
- 裁不出图的媒体直接跳过，不留空白占位
- 快速档没有表格结构 → 表格以原页裁图呈现，标注"原图，快速档不解析表格结构"

实测：204 段 / 14 表 / 7 图 / 2 公式，混排顺序正常。

## 坑
