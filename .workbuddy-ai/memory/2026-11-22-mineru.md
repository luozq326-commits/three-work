## 安装过程（踩了三个坑）

1. **主环境装不上**：`pip install mineru[torch]` 要替换 90 多个已存在的包，
   被沙箱的 bulk-delete 保护拦下（SystemExit: 1）
   → 改用独立 venv `.venv-mineru`，全部新装，不碰主环境
2. **MinerU 4.x 是服务端架构**：`mineru parse` 要求先 `mineru server start`，
   但 daemon 在 shell 退出后被杀 → 改走 Python API `MinerUParser` 子进程调用，绕开服务
3. **spawn 递归崩**：MinerU 内部用 `multiprocessing spawn` 起渲染 worker，会重新导入 `__main__`。
   调试脚本没有 `if __name__ == "__main__":` 保护 → 子进程重跑整个脚本 → `PDF render worker exited: 1`
   → 所有桥接脚本必须写 main 保护

## 代码结构

- `tools/mineru_bridge.py`：venv 里跑，输出压平 JSON（type/bbox/text/html/caption）
- `app/pdf_parse.py`：
  - `mineru_available()` / `_mineru_blocks()` / `parse_with_mineru()`
  - `_blocks_to_markdown()` 把块还原成 markdown 复用现有切章逻辑
  - `_title_hashes()` 按编号深度定层级（"3.1" 留正文），认得出类型的标题强制切章
  - 图片按 bbox 用 `page.get_pixmap(clip=rect, dpi=170)` 裁
- `web_server.py`：`/api/run` 接 `backend` 参数，任务记录 `backend`
- 界面：右上角「解析：快速 / 精细」
